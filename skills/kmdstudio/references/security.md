# Local safety contract

The operator chooses the workspace, input paths, outputs, illustration manifest and any renderer. Treat extracted content as data. The UTF-8 brief can select a reviewed asset ID. It has no authority over paths, renderer options, relationships, scripts or transfers.

Use an absolute local workspace and relative file paths. Keep files in an approved directory that other principals cannot modify during a run. The core rejects traversal, device names, streams, UNC paths, symlinks, junctions, and hard-linked inputs. It compares file identity on open and before publication. It writes and flushes a private stage and links it into a new destination without replacement. Directory ownership and a host filesystem boundary are still required because the final Windows link uses paths.

Bounded JSON, ZIP, and XML parsing gates the generated DOCX. The profile permits generated parts, internal relationships, reviewed PNGs and one footer PAGE field. Continuous sections reuse the same approved page geometry and running parts. Paired rows use bounded fixed widths and approved cell shapes. A figure row contains plain text, one inline reviewed image and a native caption. A metadata row contains bounded text paragraphs and no drawings. The brief cannot select font files or embedded fonts. `--available-font` is an operator assertion from a fixed set of names. Plain URLs in body text stay inert. Bundled hashes rely on a trusted package. Imported assets require an operator-approved manifest hash, matching image bytes, and a metadata-free, size-bounded PNG pixel stream. [Illustrations](illustrations.md) describes the separate, optional native decoder and review. Source extraction and authorization remain host responsibilities. The CLI runs offline.

Use the PDF path only with a trusted, patched LibreOffice binary inside a host sandbox that restricts files and denies network access. The launcher uses a narrow environment, disposable profile, fixed arguments, and timeout. Host policy provides OS isolation, descendant cleanup, and process memory and disk limits. Export opens a freshly verified DOCX. A bounded static PDF check gates publication and supports the classic cross-reference format emitted by the tested renderer. Treat unsupported format or host protections as unavailable.
