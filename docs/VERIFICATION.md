## Rendering and sandbox evidence

LibreOffice Writer 26.8.3.1 rendered the synthetic inputs through the CLI with Codex CLI 0.171.0-alpha.13.2 in `workspace-write` and with its network flag disabled. The PDF structural gate passed all three final diagnostic exports. All source paragraphs were visible and present in PDF text extraction. The side-by-side comparison cells required plain extraction because layout extraction interleaves the columns. Ghostscript 10.03.1 rasterized the synthetic outputs at 125 dpi with `SAFER` active.

**BLOCKED** for qualified PDF delivery on this host. A Python descendant could connect to a local listener in the sandbox. A separate connection probe to a reserved TEST-NET address also returned success. The runner identity matched the subject of the active Windows offline firewall rule. The behavior persisted with the built-in workspace profile and the elevated Windows sandbox mode. The renderer profile isolates LibreOffice state. The host supplies file and network restrictions, and this host did not demonstrate the required network denial. The synthetic diagnostic PDFs remain under the ignored `.tools/kdl-bench/` directory. The delivery directory includes the verified DOCX and PNG previews.

## Visual benchmark review

All nine final pages were reviewed at full-page scale and compared with nine baseline pages. The rubric uses 1 for a readability problem, 2 for readable with an observable weakness, and 3 for clear in the inspected renderer. Scores are reviewer observations. Exact editable content and structural validity were assessed with separate checks.

| Benchmark | A4 pages | Hierarchy / composition / readability | Observed changes |
| --- | ---: | --- | --- |
| Russian Python OOP lecture | 5 → 5 | 2 → 3 / 2 → 3 / 2 → 3 | The navy cover and ruled heading levels differentiate chapters. Fine diagram rules distinguish the sequence from the definition. The code grows from 10 to 11 pt. The description column gains space, and the practice page has a visible final takeaway. |
| Workshop Pilot Status | 1 → 1 | 2 → 3 / 3 → 3 / 2 → 3 | Georgia display type separates the title from the operational summary. Table widths change from thirds to 50/25/25%, and table type grows from 10 to 11 pt. The decision stays visible immediately after the evidence. |
| Read the Street | 3 → 3 | 2 → 3 / 2 → 3 / 3 → 3 | A burgundy rule and serif hierarchy establish the cover and chapters. The staged observation uses lighter separators. The comparison gains a divider, and printable square markers distinguish checks from ordered practice steps. |

The review caught a Writer rendering problem with four-sided borders over shaded paragraphs. The delivered version uses a single side rule for these panels. The rerender shows the cover title, code identifiers and all callouts. Sections with intentional page starts still leave generous bottom space in the lecture. The optional editorial canvas tint rendered white in this host, so the editorial palette relies on the independently visible text, rules and shading.

See the [benchmark inputs and reproduction notes](../examples/benchmarks/README.md) and the [before-and-after previews and DOCX files](../artifacts/v0.2.0).
