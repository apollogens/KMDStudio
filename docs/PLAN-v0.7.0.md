The existing blocks support the main editorial relationships, yet the installed guidance starts from profiles and individual controls. It provides few choices driven by reading tasks or visual counterexamples. The previous report gives the cover a page of its own and puts evidence and actions in one dense sequence. The lesson and catalogue establish useful patterns, with limited evidence about longer sequences or a typography-led transactional page.

1. Route substantial creative and hybrid work to a compact decision workflow, composition studies and contrasting examples. Keep ordinary structured work on its existing path. Keep the research atlas outside the ZIP.
2. Use the frozen sources below. Compose with existing native blocks, choose image roles before making original art, and qualify type in actual output. Add a composition primitive only if a specific benchmark warrants it. Investigate modern Word mode first in a disposable synthetic copy.
3. Verify exact source, graphics, assets and retained structured bytes independently. Render, record visual findings and correct targeted defects. Reproduce from the clean ZIP, publish the draft candidate and observe the existing four hosted jobs. Document owner holdout and matched-agent requirements separately.
