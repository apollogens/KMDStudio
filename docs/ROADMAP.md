# Roadmap

## Completed

The editable DOCX core, KDL profiles, native Word components and portable packages are verified. The 0.3.0rc1 and 0.4.0rc1 candidates added approved raster art, continuous columns and reference-led composition. The 0.5.0rc1 candidate adds creative and hybrid planning, editable editorial treatments and reproducible byte-level checks for structured generation. See the [project status](PROJECT_STATUS.md).

## Next milestone

Obtain blinded owner feedback on the 0.5.0rc1 report pair and the Russian lesson. Check keyboard navigation, heading order, column transitions, layout-row announcements, image descriptions and repeating table headers in Word with assistive technology. Convert observed issues into specific portable acceptance checks. Qualify a standalone Codex host with the randomized local-tool probe before running one matched agent comparison. Separate source fidelity, editability and approval behavior from preliminary visual judgments.

Keep PDF qualification separate. The renderer host must demonstrate descendant file and network restrictions before delivery. A stable release also requires independent security review, an owner-approved redistribution license, and completed product acceptance on the supported CI matrix. PPTX and more complex technical diagrams are deferred.
