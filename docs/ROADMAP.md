# Roadmap

## Completed

The editable DOCX core, KDL profiles, native Word components and portable packages are verified. Earlier candidates added reviewed raster art, continuous columns, creative and hybrid planning, native data bars and correction records. The 0.7.0rc1 candidate maps design decisions to native controls, demonstrates five edited documents, retains the structured byte-level regression and verifies an optional modern Word mode with the Accessibility Assistant on one lesson. See the [project status](PROJECT_STATUS.md).

## Next milestone

Obtain blinded owner feedback on the report comparisons and collect one unseen owner task using the frozen acceptance protocol. Qualify a standalone Codex host with the randomized local-tool probe, then run one matched ordinary, 0.6.0rc1 and candidate comparison. Use defects from that review to prioritize changes. Test keyboard traversal, reading order and layout-row announcements with an authorized assistive-technology setup. Qualify one optional open display or body family only when its approved files and target renderer are available.

Keep PDF qualification separate. The renderer host must demonstrate descendant file and network restrictions before delivery. A stable release also requires independent security review, an owner-approved redistribution license, and completed product acceptance on the supported CI matrix. PPTX and more complex technical diagrams are deferred.
