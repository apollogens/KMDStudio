# Roadmap

## Completed

The editable DOCX core, KDL profiles, native Word components and portable packages are verified. The 0.3.0rc1 and 0.4.0rc1 candidates added approved raster art, continuous columns and reference-led composition. The 0.5.0rc1 candidate added creative and hybrid planning and editable editorial treatments. The 0.6.0rc1 candidate retains the structured byte-level regression and demonstrates evidence-based corrections, tested typography and native proportional data bars. See the [project status](PROJECT_STATUS.md).

## Next milestone

Obtain blinded owner feedback on the new report and lesson pairs. Evaluate an explicit modern Word compatibility target so the Accessibility Assistant can scan the generated document. Verify its package changes independently and compare pagination and established structured output. Test keyboard traversal, reading order and layout-row announcements with an authorized assistive-technology setup. Qualify a standalone Codex host with the randomized local-tool probe before running one matched agent comparison.

Keep PDF qualification separate. The renderer host must demonstrate descendant file and network restrictions before delivery. A stable release also requires independent security review, an owner-approved redistribution license, and completed product acceptance on the supported CI matrix. PPTX and more complex technical diagrams are deferred.
