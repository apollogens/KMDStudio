# Roadmap

## Completed

The editable DOCX core, KDL profiles, native Word components, packaged skill, and three 0.2.0 benchmarks are verified. The 0.3.0rc1 candidate adds reviewed illustration import, six portable benchmarks in total, and a public verification workflow. See the [project status](PROJECT_STATUS.md).

## Next milestone

Run the controlled ordinary, previous, and candidate comparison from a standalone Codex session after a real local-tool smoke succeeds. Score source fidelity, editability, approval behavior, and artifact creation before expanding the run. Collect independent gallery and listing design feedback. Check Word keyboard navigation and screen-reader reading order with the target fonts.

Keep PDF qualification separate. The renderer host must demonstrate descendant file and network restrictions before delivery. A stable release also requires independent security review, an owner-approved redistribution license, and completed product acceptance on the supported CI matrix. PPTX and more complex technical diagrams are deferred.
