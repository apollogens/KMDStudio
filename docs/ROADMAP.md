# Roadmap

## Completed

The editable DOCX core, KDL profiles, native Word components and portable packages are verified. The 0.3.0rc1 candidate added reviewed illustration import and hosted verification. The 0.4.0rc1 candidate adds continuous columns, illustrated covers and text-and-figure composition. A Russian networking workbook demonstrates the reference-to-layout workflow. See the [project status](PROJECT_STATUS.md).

## Next milestone

Qualify a standalone Codex host with the randomized local-tool probe, then run one matched comparison across ordinary Codex, 0.3.0rc1 and the current package. Score source fidelity, editability, approval behavior and artifact quality before expanding the evaluation. Obtain blinded human feedback on the networking preview pair. Check keyboard navigation, heading order, column transitions, layout-row announcements, image descriptions and repeating table headers in Word with assistive technology.

Keep PDF qualification separate. The renderer host must demonstrate descendant file and network restrictions before delivery. A stable release also requires independent security review, an owner-approved redistribution license, and completed product acceptance on the supported CI matrix. PPTX and more complex technical diagrams are deferred.
